# AI training

Administrator supplies project-specific knowledge docs. Extraction produces bounded chunks. Test questions retrieve only that project's chunk texts by sparse cosine similarity plus lexical match, then include them as untrusted reference data in Gemini requests. Missing matching documents stops response and recommends human handoff. Playground does not send customer messages.

For full specification, independent deterministic checks for pricing, discounts, supported features and approved claims are mandatory before any automatic sending. Build a reviewed test bank for objections, Uzbek/Russian language, prompt injection and hallucinations. Project approval currently checks manually reviewed passing tests, not the complete acceptance matrix.
